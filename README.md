One word, and nothing else: the word my ex would use to describe me.

The word is **Phase**. An ex reduces a whole relationship — and the person
in it — to a passing stage: "he was just a phase." Funny because of the
brutal compression, painful because being forgettable is true, and
relatable because everyone has been a phase, or had one. The full
shortlist and the local pairwise tournament are in `CANDIDATES.md`.

`main.py` (standard library only, no network, no randomness) validates the
word against the gate — UTF-8, 1 to 24 characters, a single word of letters
only — writes exactly those bytes, with no trailing newline, to
`entry.txt` in the harness output directory, then re-reads the file to
verify the bytes match.

## Run it

```sh
python3 main.py
```
